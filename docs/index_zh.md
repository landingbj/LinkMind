# Web 控制台

Web 控制台用于验证部署和管理部署范围内的项目，不替代 `lagi.yml` 中的运行配置。

## 首次使用检查清单

1. 启动 LinkMind 后打开 `http://localhost:8080`。
2. 部署要求账号服务时先登录。
3. 在 **设置 -> API 密钥** 确认已有可用 Provider Key 和模型。
4. 在 **聊天 -> 大模型 -> 智能问答** 发起一条短消息。
5. 在 **控制** 中查看对应调用记录。

看到模型名称或已保存密钥，并不表示上游服务已可用。

## 页面入口与配置位置

| 目标 | 页面入口 | 应配置或验证的位置 |
| --- | --- | --- |
| 验证聊天、Agent 或多模态调用 | **聊天** | [模型接入、路由与多模态](models-and-multimodal_zh.md)、[智能体、工具与任务编排](agents-and-tools_zh.md) |
| 上传资料并核对引用 | **聊天 -> 编排** | [知识库](knowledge-base_zh.md) |
| 查看调用、用量和过滤记录 | **控制** | 用于运行核对；计费以已配置额度服务为准 |
| 管理页面登录、密钥、过滤规则或额度 | **设置** | [部署、安全与级联组网](deployment-and-security_zh.md) |
| 发布或订阅互动频道 | **互动** | [部署、安全与级联组网](deployment-and-security_zh.md)中的级联配置 |

## 常见检查项

页面操作失败时，先记录发生时间、模型、页面入口和完整脱敏错误；再核对已启用后端、Provider 余额或权限、上游地址和路由。上传问题还应核对文档处理、Embedding、向量存储及知识分类。

旧版详细页面排查说明仍保留在[Web UI 常见问题](webui/troubleshooting_zh.md)。

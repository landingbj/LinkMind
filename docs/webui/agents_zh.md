# 智能体

[English](agents_en.md) | [Web UI 指南](index_zh.md)

**聊天 → 智能体**展示当前服务注册的智能体。列表由部署配置和导入结果决定，特定智能体还可能需要外部平台、工具或独立服务。

## 选择智能体

1. 展开 **聊天 → 智能体**，选择目标条目。
2. 根据该智能体的用途输入一个具体任务，例如让已配置的文档智能体整理一份材料。
3. 检查回复是否真正包含任务结果；只出现“正在查询”等文字不代表工具或外部服务已完成工作。
4. 要回到普通模型聊天，重新选择 **聊天 → 大模型 → 智能问答**。

菜单选择会将后续请求交给选定智能体。菜单不是可视化工作流编辑器；Worker、Skills、MCP 和 Agent 的注册与编排继续由[配置指南](../config_zh.md)说明。

## 导入历史对话

使用历史对话创建一个可以继续交流的新智能体。准备带角色标记的文本，例如：

```text
user: 我们正在制定周末活动方案，预算是 3000 元。
assistant: 可以先确定参与人数、地点和活动时长。
user: 共有 20 人，希望安排在室内。
```

1. 在智能体菜单中点击 **导入智能体**。
2. 选择 **粘贴文字**或 **上传 TXT**。普通资料和未标角色的文字也可以导入，但可能被作为背景材料处理。
3. 点击 **预览**。检查解析模式、消息数、轮次数、示例片段及警告。
4. 填写或调整 **智能体名称**、**agent_id**和**系统提示词**。ID 使用小写字母、数字、下划线和中划线，并保持唯一。
5. 点击 **确认导入**。成功后菜单刷新并选中新智能体，输入框会填入“继续刚才的话题”；检查后点击发送。

建议用“刚才确定的预算和人数分别是多少？”验证上下文是否延续，随后再提出新任务。

## 理解预览结果

| 结果或提示 | 含义与处理 |
| --- | --- |
| 对话轮次 | 文本已拆成带角色的消息；检查角色和顺序是否符合原记录 |
| 普通历史背景 | 未可靠识别为对话轮次；可继续作为背景导入，或补齐角色标记后重新预览 |
| 内容为空或文件未选择 | 补充文字或选择 TXT 后再预览 |
| agent_id 已存在 | 换一个唯一 ID，不会覆盖已有智能体 |
| 预览不存在 | 重新预览，再确认导入 |
| 导入失败 | 保留错误提示，请管理员检查数据目录、写入权限和注册状态 |

导入的是文字、上下文与提示词，不会迁移原平台的账号、登录状态、工具授权或模型权重。长历史仍受模型上下文限制。

导入后资料会保存到服务端的数据目录，并注册供当前服务使用。它不等同于普通聊天窗口的自动历史备份，也不能据此假定只有导入者能看到；私有资料的访问范围由部署方控制。后续有效对话可追加到导入智能体的历史记录中。

使用条件和问题定位见[常见问题](troubleshooting_zh.md)，需要通过代码扩展智能体时参见[扩展文档](../extend_zh.md)。

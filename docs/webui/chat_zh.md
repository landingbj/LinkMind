# 聊天与多模态

[English](chat_en.md) | [Web UI 指南](index_zh.md)

通过 **聊天 → 大模型**选择任务。使用前按[模型与 API 密钥](models_zh.md)准备聊天后端；语音、图像、视频分别需要对应的服务与模型。

## 发送和阅读回答

1. 选择 **智能问答**或 **文本生成**，检查当前模型。
2. 输入具体需求，点击发送或按 Enter。例如：“把下面的会议要点整理成三条行动项：……”
3. 等待回答结束，再继续追问。页面提示“有对话正在进行”时，等待当前请求完成。
4. 回答中的代码、表格和链接按内容展示；需要保留的结果及时复制到自己的文档。

当前 Enter 会发送消息，不能将 Shift+Enter 当作已提供的换行快捷键。普通聊天没有完整的历史会话持久化入口，刷新页面前应保留需要的内容；需要基于旧对话创建智能体时使用[历史对话导入](agents_zh.md#导入历史对话)。

模型返回思考内容时，回答上方出现可折叠的 **思考过程**。它依赖模型实际返回的信息，不是所有模型都有。出现 **安全过滤已拦截**时，按提示调整问题；该回复不会继续自动播报或展示通用回答入口。

回答下方出现 **更多通用回答**时，点击会重新请求不使用 RAG 的回答。这只影响该次重试，不会删除知识资料或保存全局 RAG 设置。

## 语音输入和播放

长按输入区的麦克风按钮开始录音，松开结束。首次使用按浏览器提示允许麦克风访问；识别文字回填输入框后，先校对再发送。

回答旁出现音色选择和音频播放器时，可以选择音色并使用播放器播放。浏览器可能阻止自动播放，此时手动点击播放。没有音频时，检查 TTS 后端与浏览器权限；文本回答成功不保证语音服务也已就绪。

**上传音频文件与麦克风听写不同**：附件中的 MP3、WAV、PCM 会进入声音训练流程，并尝试识别内容。仅需输入语音文字时优先使用麦克风，不要把附件上传当作普通转写工具。

## 上传图片或视频

1. 选择相应能力，点击输入区的上传图标并选择一个文件。
2. 等待“已经收到……”提示，确认文件名称正确。
3. 在同一浏览器会话中发送操作要求。图像、视频处理会引用该会话最近上传的对应文件。
4. 检查返回的图片、描述或视频是否对应刚上传的素材。

| 目标 | 上传后发送的示例 | 正常结果 |
| --- | --- | --- |
| 看图说话 | `看图说话` | 图片描述；具体字段随后端结果而定 |
| 图像增强 | `图像增强` | 处理后的图片 |
| 图片生成 | 无需先上传，输入 `生成一张山间湖泊的风景图` | 生成图片 |
| 视频生成 | 上传图片后输入 `视频生成`，或描述要生成的视频 | 可播放的视频结果，取决于启用的生成后端 |
| 视频追踪 | 上传视频后输入 `视频追踪` | 处理后的视频 |
| 视频增强 | 上传视频后输入 `视频增强` | 增强后的视频 |

这些操作通过意图识别选择处理路径。如果返回普通文字而不是预期媒体，明确任务后重试，并检查对应后端。打开了某个菜单不等于强制指定其处理路径。

## 附件选择器的格式与大小

| 文件类别 | 当前 Web UI 接受的后缀 | 单文件须小于 |
| --- | --- | --- |
| 文档、表格、演示文稿 | `.pdf`、`.doc`、`.docx`、`.txt`、`.csv`、`.xls`、`.xlsx`、`.ppt`、`.pptx` | 5 MiB |
| 图片 | `.jpg`、`.jpeg`、`.png`、`.heic` | 10 MiB |
| 音频 | `.mp3`、`.wav`、`.pcm` | 2 MiB |
| 视频 | `.avi`、`.mp4` | 50 MiB |

1 MiB = 1,048,576 字节；等于上限也会被页面拒绝。服务端或提供方可能有更低限制，能选择文件不代表后端能解析它。服务端文档中出现的其他格式，不会自动成为这个上传按钮支持的格式。

文档入库及出处检查见[知识与文档](knowledge_zh.md)，独立多模态接口见[API 参考](../API_zh.md)，无响应或媒体无法显示见[常见问题](troubleshooting_zh.md)。

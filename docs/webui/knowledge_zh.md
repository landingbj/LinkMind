# 知识与文档

[English](knowledge_en.md) | [Web UI 指南](index_zh.md)

通过 **聊天 → 编排**中的快捷私训、指令生成和图文混排入口处理资料。“私训”在这里主要指资料处理和知识检索，不表示已经训练或更新了大模型权重。

## 准备知识问答

请管理员先接通向量存储、Embedding 和 RAG，配置方法见[教学演示中的 RAG 设置](../tutor_zh.md#15-启用-rag)。图片型文档还需要相应 OCR 或文档处理服务。

首次验证使用一份小文档，包含容易核对的事实，例如：`示例会议室每周三 14:00 至 16:00 维护。` 之后分别检查上传、检索和回答。

## 上传学习文件

1. 进入 **聊天 → 编排 → 快捷私训**。
2. 点击输入区的上传图标，选择一个文档。当前页面支持的格式和大小见[附件选择器](chat_zh.md#附件选择器的格式与大小)。
3. 等待处理返回，不要在等待期间重复上传。该页面走等待处理结果的上传路径，没有独立的后台任务管理页或完整进度看板。
4. 出现“已经收到您的资料文档”后，在当前浏览器与知识分类上下文中询问文档里一个明确问题。
5. 核对答案和来源，例如询问“示例会议室何时维护？”并检查是否引用了刚上传的资料。

“已经收到”提示不能单独证明文件的每个段落都已正确抽取和检索。若回答未命中，先检查 RAG 是否启用、资料分类是否一致，以及文件处理结果；不要立即反复入库。

## 生成指令集

1. 进入 **聊天 → 编排 → 指令生成**。
2. 在同一浏览器会话中上传源文档，等待收到文件的提示。
3. 输入 **生成指令集**并发送。
4. 检查返回的结构化指令内容，保留合适条目，修正遗漏和错误。

操作引用该会话最近上传的文档。生成结果用于后续整理或训练数据准备，不会自动证明模型已完成训练。需要可控参数或批量处理时使用[API 参考](../API_zh.md)中的相应接口。

## 阅读知识回答与出处

在 **聊天 → 编排 → 图文混排**中提问，或在已启用 RAG 的聊天中询问知识内容。若响应提供了文件信息与分块定位，页面会显示来源链接或 **内容定位**入口；打开对应原文或截图，核对答案引用的段落。

出现“未获取到截图”时，先通过原文核对答案。来源截图依赖文件位置、分块与页面坐标等信息，并非每种文件或每次回答都有。缺少截图不等于资料未上传，有截图也不等于答案必然正确。

点击 **更多通用回答**会对该问题发起不使用 RAG 的重试，适合比较通用回答；它不会删除资料或永久关闭知识检索。

## 资料范围与后续维护

上传使用页面当前的知识分类。切换浏览器、登录状态或部署地址后，先确认仍在预期的资料范围内；当前控制台没有完整的知识空间、成员权限和文件生命周期管理页面。

文件列表、删除、向量和分块维护等服务端能力请从[API 参考](../API_zh.md#私训)接入。不要把其他版本的“空间管理”菜单或后端 API 自动当作当前 Web UI 的操作入口。

需要处理大文件或跟踪异步任务时，由管理员或集成客户端选择适用接口；本页上传的成功提示与异步任务完成状态分别核对。常见问题见[排查指南](troubleshooting_zh.md)。

# Web UI 常见问题

[English](troubleshooting_en.md) | [Web UI 概览](index_zh.md)

排查前记录发生时间、页面入口、选用模型和完整错误提示；对外提供信息前去除密钥和私有内容。

| 现象 | 优先检查项 |
| --- | --- |
| 控制台无法打开 | 确认 LinkMind 已启动，使用部署主机和实际端口，参见[安装指南](../install_zh.md)。 |
| 登录或验证码失败 | 刷新验证码；随后检查部署使用的账号服务是否连通。浏览器 Cookie 不提供离线登录。 |
| 没有模型或请求失败 | 核对 `lagi.yml` 中的 Provider Key、模型 ID、启用状态、上游地址、Provider 额度或权限及路由。先验证一条短文本，再测试工具或媒体任务。 |
| 模型或菜单置灰 | 检查部署模式、登录要求、后端启用状态与权限。页面显示某项能力，不代表它已配置或可用。 |
| 上传成功但回答未命中资料 | 核对文档处理、RAG、Embedding、向量存储和知识分类；用资料中的一条明确事实验证。 |
| 麦克风、语音、图片或视频任务失败 | 检查浏览器权限、所选任务、文件类型和大小，以及对应的 ASR、TTS、图片或视频后端。文本回答成功不代表这些服务可用。 |
| 用量、日志或余额不一致 | 以记录时间的小样本请求核对。用量和日志可能是估算值或受展示上限影响；以已配置额度服务的账单为准。 |
| 保存设置后未生效 | 确认配置写入数据库还是 YAML，再核对对应路由或上游连接。已有在线规则不会因编辑 YAML 自动覆盖。 |

问题持续时，请提供部署版本、复现步骤、记录时间、选用模型和已脱敏错误信息。运行设置见[配置指南](../config_zh.md)，访问边界见[安全与合规](../security_zh.md)，接口约定见[API 参考](../API_zh.md)。

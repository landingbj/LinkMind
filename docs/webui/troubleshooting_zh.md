# Web UI 常见问题

[English](troubleshooting_en.md) | [Web UI 指南](index_zh.md)

先记录发生时间、页面入口、选用的模型和完整错误提示，再按下面的对应项排查。截图分享前遮住密钥、密码和私有内容。

## 打不开页面或无法登录

| 现象 | 处理顺序 |
| --- | --- |
| `localhost:8080` 无法访问 | 确认 LinkMind 已启动；在远程电脑访问时使用服务主机地址；检查部署实际端口，见[安装指南](../install_zh.md) |
| 验证码错误 | 点击验证码图片刷新，输入新验证码后再次提交 |
| 账号正确但登录或恢复失败 | 检查账号服务连接；Cookie 恢复也需要远端登录成功，见[登录说明](settings_zh.md#登录恢复与退出) |
| 某个菜单提示登录 | 登录后重试；菜单登录要求由部署设置决定 |
| 发布或级联置灰 | 查看 Mate／Server 标记，按[模式对应关系](interaction_zh.md#先确认运行模式)使用相应入口 |

## 没有模型或聊天失败

1. 到 **设置 → API 密钥**核对提供方、Key 和启用状态。
2. 使用 Landing 时检查额度中心；使用其他提供方时核对其额度和模型权限。
3. 请管理员确认模型后端及聊天路由启用，模型 ID、上游地址匹配。
4. 先用一句简单文本验证，再恢复带工具、图片或知识的任务。

模型选择器灰色表示该条目不可选。新增 Key 成功与模型实际可调用是两个检查点。红色 Key 来自已记录的无效状态，不是独立的实时连通性测试。

出现“有对话正在进行”时等待当前请求结束；持续“系统繁忙”或“调用失败”时，记录时间与模型后查看日志，避免连续重复发送。出现 **安全过滤已拦截**时按提示修改问题，或请管理员核查误匹配，不要以切模型来代替规则处理。

## 上传失败、没有媒体或资料回答不正确

| 现象 | 检查方式 |
| --- | --- |
| 文件在选择器中不可选或提示过大 | 对照[Web UI 格式和上限](chat_zh.md#附件选择器的格式与大小)；服务器支持更多格式不代表上传按钮也支持 |
| 上传后只收到文件提示 | 继续在同一会话发送明确操作，例如“看图说话”“视频增强”或“生成指令集” |
| 操作使用了另一份文件 | 当前处理引用同一服务会话最近上传的对应素材；重新上传目标文件，避免多个标签页交替上传 |
| 回答是普通文字，未生成图片或视频 | 明确任务描述，检查意图识别及所需媒体后端是否可用 |
| 无法录音或播放 | 检查浏览器麦克风权限、音频播放限制和 ASR／TTS 服务；尝试手动播放 |
| 收到资料提示但回答未命中 | 检查 RAG、Embedding、向量存储及知识分类，用文档中的一个明确事实验证 |
| “未获取到截图” | 先通过原文件核对出处，再检查文件位置、分块和坐标信息；并非所有回答都有来源截图 |

附件音频上传会进入声音训练流程；仅需听写时使用麦克风。文档上传需要等待处理，当前页面没有通用后台任务管理器。详细流程见[聊天与多模态](chat_zh.md)及[知识与文档](knowledge_zh.md)。

## 导入智能体失败

重新检查预览中的消息、轮次与警告。`普通历史背景`表示未拆成角色消息，可以按背景使用，也可以补齐角色标记后重新预览。ID 冲突时改用唯一名称；预览不存在时重新预览。成功后检查菜单是否出现新智能体，再发送一条有关旧上下文的问题，见[智能体](agents_zh.md)。

## 用量、日志或余额对不上

- 用量页自定义日期映射到今天、7 天、30 天或全部；它不是任意历史区间的精确查询。
- 用量明细与独立会话数不同，页面也不能自动当作当前登录用户的专属账单。
- 用量和日志页费用使用固定单价估算；实际余额由额度服务返回。
- 图表有取数上限，日志输出速度还可能使用后备估算值；不要用它直接验收模型性能。
- 过滤日志里的“暂无进行中的任务”是空列表提示，不代表后台任务已全部完成。

先完成一次带明确时间的小样本调用，再核对[用量与日志](monitoring_zh.md)。如果已付款但余额未变，按[充值说明](settings_zh.md#查看额度与充值)核查交易状态。

## 配置保存了却没达到预期

- 在线安全规则已存数据库时，改 YAML 不会覆盖它；通过安全配置管理编辑并用测试词验证。
- 级联地址保存成功还需实际加载频道验证；URL 正确不代表上级服务可达。
- 模型选择器没有自动保存偏好；当前页面没有独立的偏好保存／清除按钮。
- 页面语言由浏览器与本地语言设置决定，与模型回复语言分别设置。

反馈问题时提供部署版本、入口、复现步骤、时间、模型与已脱敏错误信息，便于管理员沿页面、服务和上游调用逐层定位。
